about

Where analytics meets bespoke software

AT&T set out to overhaul their fraud detection tool to mitigate fraudulent activity involving physical hardware. The work lived at the intersection of custom analytics and internal workflow software — informing and empowering in-house investigators.

The challenge was dual: build a more accurate detection surface, and give users the tools to adapt the system as fraud patterns shift.

approach

Three design objectives

  • _01Improve true positivesIncrease correctly identified fraud, minimizing fiscal losses.
  • _02Reduce false negativesCut erroneous flags that damage customer relationships.
  • _03Build for modularityLet investigators customize fraud workflows as new patterns emerge.
